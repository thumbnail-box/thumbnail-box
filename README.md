Commodore Amiga（1985年発売）の独自カスタムチップ**「Copper」**を、詩的に読み解くテストアートです。

コッパー指令の `WAIT` 命令を「間（ま）」とし、パレットレジスタの変更を「筆致」と見なします。
1フレーム＝50Hzという時間制約の中で、意図した創作が展開できるか。
